# 渐进式视频生产

> 正式制作、已有素材继续创作，或需要决定下一步时读取。

## 北极星

客户负责目标、审美和关键取舍；当前宿主 Agent 负责把作品做出来。Skill 规范方法，资产保存事实，
ComfyUI 提供 workflow-as-code 操作面。不要为此再造 Agent Runtime、App、CLI 产品或画布。

生产循环不是固定阶段表：

```text
读取事实 → 选择下一项高判断价值产物 → 生成/展示 → 客户反应 → 整理来源 → 继续或交付
```

## 1. 读取，而不是重新盘问

先读取用户消息、所选文件、项目 `project.md`、`assets.md`、`decisions.md` 和已有 workflow。
已经明确的内容不要重复确认。只有缺失信息会改变方向、授权或本次成本时才问。

判断本次任务：

- **直接任务**：目标明确、低成本、单一产物，可直接完成并展示。
- **渐进任务**：创意不确定、素材复杂、多镜头或高成本，先做最能帮助判断的较小产物。

## 2. 选择下一项最有价值的产物

不要先机械完成整部片的全部规划。根据当前最大不确定性选择下一步，例如：

| 最大不确定性 | 先产生什么 |
| --- | --- |
| 风格是否合适 | 2–4 张方向/效果图或风格卡 |
| 主体是否稳定 | 角色卡、产品图处理或关键参考帧 |
| 动态是否成立 | 一个 4–5 秒关键测试镜头 |
| 叙事是否清楚 | 简短文本分镜或少量镜头计划 |
| workflow 能否运行 | doctor + dry-run；必要时经授权做最小 smoke |
| 拼接节奏是否成立 | 使用已有片段做粗剪，不先生成全部镜头 |

镜头表、完整 storyboard、批量生成只有在它们确实降低返工时才创建。客户要求逐步查看时，每个重要
可见产物后停下；客户要求少打扰时，可连续完成低风险派生，再到重要里程碑报告。

## 3. 展示产物并说明来源

不要把耐用产物只写在聊天里。创建真实文件并在对话中展示，然后用很短的话说明：

- 这是什么；
- 来自哪些输入或决定；
- 当前是 `temporary`、`candidate` 还是 `approved`；
- 下一步有哪些合理选择。

把文件和来源写入 `assets.md`。客户确认、否决或替换的稳定决定写入 `decisions.md`。

## 4. 执行技术 workflow

需要生成计算时，把 ComfyUI workflow 当代码：

1. 从正式库选择能力匹配且当前已配置的 workflow；客户也可以指定或替换。
2. 将项目修改版复制到项目 `workflows/`，不要破坏公共模板。
3. 按实例/外部服务配置解释实际字段和限制，不把当前实例配置冒充模型能力。
4. 先运行 `workflow-doctor.py` 和 `run-workflow.py --dry-run`。
5. 高成本、公开上传或新授权在真实提交前确认；已清楚授权的低风险步骤不重复询问。
6. 读取 history 和实际产物，登记客观 run 关系；不要用“共享目录最新文件”猜结果。

用户想看或接管时再打开 ComfyUI UI，展示语义输入输出及必要技术节点。默认对话中只呈现客户需要的
作品、来源和决定，不把节点编号变成客户菜单。

## 5. QC、局部返工与继续

按照 `quality-control.md` 检查候选。通过后可标记 `approved`；不通过时先定位问题层：

| 问题层 | 处理 |
| --- | --- |
| 创意/方向 | 回到较低成本方向产物，不继续烧后续额度 |
| prompt | 只修改 prompt 并生成新候选 |
| 参考资产 | 替换对应资产，只重算依赖它的下游 |
| workflow/外部服务适配 | 修本地适配或换 workflow，保留创意和资产 |
| 后期 | 用确定性工具修字幕、响度、转场、容器 |

一次只改变一个主要变量。保留旧候选，失败版本不能覆盖已批准资产。连续 3 次失败、预算耗尽、目标
漂移或需要新授权时停止；否则根据客户要求继续产生下一项最有判断价值的产物。

## 6. 交付与沉淀

交付前对照客户目前有效的要求与 `decisions.md`，检查文件完整性、规格、音轨、黑帧和不应暴露的
内部元数据。把最终文件登记为 `approved`，在有意义的里程碑做本地版本记录并告知客户；远端推送
仍需单独授权。

成功方法重复出现或客户要求保存时，按 `skill-evolution.md` 生成 Skill 草稿。保存创作知识，不把
单个项目内容、密钥或当前部署限制写成通用规则。

## 客户打断规则

| 情况 | 行为 |
| --- | --- |
| 客户已经明确要求 | 直接执行，不重复问 |
| 低成本、可逆、方向不变 | 自动执行并报告 |
| 中等不确定性 | 先做小样，让客户看见再决定 |
| 高成本、授权、公开上传、不可逆 | 执行前确认 |
| 客户要求逐步看 | 每个重要可见产物后暂停 |
| 客户要求少打扰 | 推进到下一个重要里程碑 |
| 连续失败 3 次、预算耗尽、目标漂移 | 停止并请求决策 |
