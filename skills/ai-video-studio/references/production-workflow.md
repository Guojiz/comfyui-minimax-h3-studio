# Agent 主导的视频生产

> 何时加载：正式制作广告、短片、品牌片、短剧、MV 或多镜头视频时。

## 北极星

客户描述目标并决定关键取舍；Agent 负责把作品做完。ComfyUI、模型与 workflow 只是生产工具。
默认隐藏技术编排，只在调试、复用或用户主动要求时展开。

生产不是一次性“生成整部电影”，而是可观察、可判断、可回退的循环：

`方向 → 镜头计划 → 能力选择 → 生成 → QC → 局部返工 → 成片`

## 1. 一次锁定方向与预算

从用户输入和已有素材推断能安全推断的内容，只追问会改变作品方向、授权或成本的缺口。
一次提交给用户确认：

- 目标、受众、平台、画幅、时长与交付规格
- 一句话创意与风格卡（色彩、光影、介质、节奏）
- 必须出现、禁止出现和授权边界
- `shots/index.md` 中的 shot 计划、连续性锚点与职责
- 本轮预算：计划内首轮生成次数、返工额度、停止条件

确认后，计划内首轮生成视为已授权。不要在调研、提示词、首帧和每个视频提交前重复确认。

## 2. Agent 自主准备

Agent 在后台完成：

1. 仅为未知决策做必要调研，把参考与来源存入 `references/`。
2. 优先复用角色、场景、风格、道具和已有镜头资产。
3. 为每个 shot 建立目录与 prompt，写清景别、画面、运镜、动作、台词、音效和段尾状态。
4. 长片按 `long-video.md` 拆为 4–15 秒镜头，复用同一连续性锚点。
5. 根据目标选择或组合 workflow；不要让预设 `mode` 反过来限制创意。
6. 在提交前运行 workflow 体检：

```bash
python3 scripts/workflow-doctor.py <workflow.json>
```

体检缺节点、模型或枚举资源时，先换可运行 workflow 或补依赖；不要占用付费窗口盲试。

## 3. 批量执行与留痕

同类步骤批量执行：先准备全部首帧/参考素材，验收后再生成视频。每次提交关联镜头与版本：

```bash
python3 scripts/run-workflow.py <workflow.json> \
  --project <项目目录> --shot s03 --iteration v1 \
  --set '节点ID.inputs.字段="值"' --dry-run
```

去掉 `--dry-run` 才提交。`runs/<run-name>/run.json` 保存 `shot_id`、`iteration`、参数、状态与产物，
旧 run 永不覆盖。完成一次提交后立即更新 `shots/index.md` 的状态和 `best_run`。

时间受限的模型窗口中：

- 窗口开始前完成 brief、shot 表、prompt、素材、workflow 体检和 dry-run。
- 窗口内只做已体检的生成与必要返工，不安装大模型、不研究新节点。
- 先跑最能验证整体方向的关键镜头，再批量跑其余镜头。
- 并行与否取决于后端配额；不确定时串行，避免任务相互挤压。

## 4. 自动 QC 与局部返工

按 `quality-control.md` 检查技术指标、内容符合度、连续性与声音。状态写入 `shots/index.md`：

- 通过：`generated → qc_pass`，更新 `best_run`。
- 可局部修复：`generated → qc_rework`，只重做这个 shot。
- 已进入成片：`qc_pass → final`。

返工遵循 `rework.md`。一次只改变一个主要变量，并保留旧版本用于对比。以下情况才回用户：

- 达到本轮预算上限；
- 同一镜头连续失败 3 次；
- 新结果暴露了必须改变整体方向的问题；
- 需要新的肖像、版权、公开上传或其他授权。

## 5. 合成与交付

只使用每个 shot 的 `best_run` 合成。局部修复字幕、响度、转场和容器元数据时优先使用确定性工具，
不要为剪辑问题重新调用生成模型。交付前：

- 对照已确认的目标、必含/禁含与 shot 表；
- 检查时长、分辨率、帧率、音轨、黑帧和文件完整性；
- 清除内部 prompt、模型路径、临时 URL 等不应进入交付文件的元数据；
- 把最终文件放入 `final/`，把可复用资产和有效经验沉淀回项目。

## 确认策略

| 类型 | 行为 |
| --- | --- |
| 方向、总预算、公开上传、授权 | 必须确认 |
| 已授权 shot 的首轮生成 | 自动执行 |
| 已授权返工额度内的局部重做 | 自动执行并报告 |
| 调研、提示词、体检、dry-run、QC、归档 | 自动执行 |
| 连续失败 3 次、预算耗尽、目标漂移 | 停止并请求决策 |

## 能力边界

- 快速路径的节点能力不等于 Studio 的产品边界；以当前 ComfyUI `object_info` 与 workflow 体检为准。
- 单条视频通常为 4–15 秒；长视频使用镜头计划、连续性锚点、分段生成和本地合成。
- 精选 workflow 是可移植参考，不代表本机已安装其节点、模型或素材。
- 未做真实小任务验证时，只能声称结构/dry-run 通过，不能声称端到端可用。
