# Codex 宿主映射

Codex 本身就是主 Agent、计划者、工具调用者和客户对话入口。本 Skill 不提供第二套 Agent Runtime。

- 使用对话接收目标并直接展示本地图片、视频和音频产物。
- 使用现有多模态能力检查媒体；独立、繁琐工作可用 Codex 原生子代理。
- 将 `scripts/` 视为内部确定性工具，不把命令行作为客户入口。
- 用户要求查看或接管技术 workflow 时再打开 ComfyUI。
- 项目采用 Git 后，可在批准里程碑做低风险本地提交并告知；远端 push 另行授权。
- 修改本 Skill 时调用已安装的 `skill-creator` 并重新验证。

宿主工具名称可能变化；按语义映射执行，不要把某个工具调用格式写回通用 `SKILL.md`。

执行前先确认工具清单：已暴露 `mcp__comfyui__*` 时优先走 MCP，工具名可能因宿主显示略有差异，
按语义识别；仅一次调用失败不足以断定 MCP 缺失。MCP 不可用而改用 runner 时，必须显式传入
同一锁定实例地址，并把回退原因和实际 server 写入 run 记录，禁止静默回退 localhost。
