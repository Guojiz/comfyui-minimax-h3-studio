# 接入方式

> 需要决定“这次视频在哪里生成”时读取。本 Skill 只绑定 ComfyUI，不默认任何模型或 API 服务；
> 下面的三种接入方式都支持，但每一种都必须由客户明确选择、由本机配置落地。

## 三种接入方式

### 1. 连接网络上的 ComfyUI 实例

ComfyUI 部署在远端（例如远程 GPU 平台），Agent 通过 HTTP 调用它。

- 在本地实例 catalog 登记实例（`instance_id`、显示名、规范化地址）；
- 用 `list_instances` 查看、`check_instance` 探测可达性；
- 只有一个实例时自动选择但必须显示选择结果；多个实例时由客户选择，`select_instance`
  写入项目锁，并同步记入 `decisions.md`；
- 每次 run 记录实际实例、地址与任务 ID；提交前实例不可达或项目锁不一致时停止。

### 2. 在自己电脑上部署 ComfyUI

ComfyUI 跑在本机（例如 `http://127.0.0.1:8188`）。

- 与方式 1 完全相同，只是实例地址是本机地址；
- 本机实例同样是显式选择：catalog 登记 + 项目锁，不能因为“本机”就静默默认；
- 没有显式实例时禁止向 localhost 提交。

### 3. 将别人的 API Key 接入 ComfyUI

ComfyUI 通过自定义节点调用某个第三方模型/API 服务（例如把第三方的 Key 填进节点配置）。

- 这类节点与契约配置属于**本地或项目适配**，公开仓库不随包分发任何具体服务的节点、
  workflow 模板或配置示例；
- 使用前 Agent 必须向客户确认：用哪个服务、是否已有本地配置、是否授权本次调用与
  可能的费用；没有明确选择与授权时不得默认任何服务；
- Key 只保存在本机忽略文件（`config.json`/`.env` 等），不进入对话、workflow、run 或 Git；
- 本地适配节点应复用安全基线：服务主机白名单、任务 ID 校验、下载大小上限、凭据只发给
  配置的主机；这些约束模板见 `references/comfyui-workflows.md` 与 `SECURITY.md`；
- 上传到外部服务的素材（肖像、版权内容）必须先获得授权。

## 询问规则

| 场景 | 必须问 | 可以自动做 |
| --- | --- | --- |
| 首次使用某个实例 | 是否用该实例 | 可达性检查、项目锁 |
| 首次使用某个外部服务 | 服务、Key/配置、费用、授权 | 无 |
| 同一实例/服务再次使用 | 无需重复问，但按既定配置执行 | 沿用项目锁 |
| 上传外部服务 | 素材是否可上传 | 内容哈希、来源记录 |

## 与仓库边界的关系

- 公开仓库只交付 ComfyUI 适配层、通用脚本与 Skill 方法；
- 用户的远端实例、本地实例都通过实例 catalog/项目锁落地，不写进仓库；
- 第三方 API Key 适配属于用户本地 `.local-sources/` 或项目配置，不随仓库分发。
