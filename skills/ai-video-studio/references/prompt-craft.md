## 零、H3 模型规格（写 prompt 前的硬约束）

- 输出时长 4–15 秒；24 FPS；所有结果原生带双声道声音
- 画幅：文生视频/全能参考模式支持 21:9、16:9、4:3、1:1、3:4、9:16；
  首/尾帧模式遵循输入图的原始长宽比
- 提示词上限 7000 字符；具体文字/Logo/标语必须把原文写出来
- 首/尾帧入口：0–2 张图；全能参考入口：图≤9、视频≤3（单段 2–15s、总≤15s）、音频≤3（必须配图或视频）、混合上限 12 个文件
- 输入格式：视频 H.264/H.265（内嵌音频 AAC/MP3）；图片 JPG/JPEG/PNG/WEBP/HEIC/HEIF；音频 WAV/MP3
- 单文件大小：视频 50MB、图片 30MB、音频 15MB（限制在单个素材上）；API 请求体 64MB，优先用 URL 传素材
- 分辨率：768p 模式短边 768px（21:9 时 1536×672）；1440p 模式短边 1440px（21:9 时 2976×1248）
- TTS 精准覆盖 11 种语言（中英日韩法德西等），台词可直接写目标语言

## 一、官方三段公式（最高优先级）

```
完整提示词 = 参考素材说明 + 核心创意 + 画面过程说明
```

长片可追加第四段 `【整体要求补充】`，用 `▍` 分节写贯穿全片的规则
（影像风格 / 文字包装 / 律动规则 / 景别切换 / 人物规则 / 禁止项 / 环境音）。

### 1. 参考素材说明

- 按上传顺序编号引用：`@图片1`、`@视频2`、`@音频3`
- 每个素材必须写清用途，官方用途词表：
  人物参考（锁脸）/ 物体参考 / 场景参考 / 关键帧（首帧/尾帧明确提出）/
  音色参考 / 故事版 / 风格参考 / 构图参考 / 音频复用 / 音频部分复用 /
  动作参考（锁动作）/ 运镜参考（锁运镜）/ 视频编辑（增删改）
- 想保持的特征明确写出来（发型、服装逐项列）；音频复刻若要求歌词保持，
  必须把歌词文本原文附在提示词里
- 无上传素材时整段跳过

### 2. 核心创意（一句话锁全片）

必含四要素 + 可选运镜：
- **主体**：谁/什么（具体可见名词：外观、服装、材质）
- **地点**：在哪里
- **事件**：在做什么
- **题材/风格**：写实/动画/电影感/广告片/纪录片/赛博朋克……
- **特殊运镜**（可选）：航拍/一镜到底/慢动作。**默认会切镜**；
  要一镜到底必须明说且全文保持一段情节描述
- 示例：`一位穿汉服的年轻女子（@图片1）在樱花纷飞的庭院里舞剑，古典国风，电影质感，一镜到底。`

### 3. 画面过程说明（按时间轴/shot 分段）

每个 shot 写齐六项：**景别 + 内容 + 运镜 + 动作 + 台词 + 音效**。
- 以切镜 shot 作为时间戳分段，如 `0-3秒：全景，……`
- 台词长短必须与 shot 时长对齐（口型问题的头号来源）；
  跨 shot 台词明确写"接着上个 shot 继续说"（H3 支持 J-cut/L-cut）
- 说话人写清楚：画面内角色点名，画外写"画外音/画外说话人"；
  切镜造成的画内外转换要明确写出
- 切镜时写明切到什么景别、主体是之前的哪个角色（跨镜头一致性）
- 想出现具体文字必须给原文：`手机屏幕上显示标题："AI Video Creation"`
- 正向表述优先：少写比喻句，多写看得见的画面

### 4. 声音控制

- 不要背景音乐时必须显式写：`非叙事性音乐：N/A` 或 `"non_diegetic_music": N/A`
- "要音乐"和"不要 BGM"同时出现是矛盾，必须二选一或分场景写
- 环境音可以白名单式列出（官方手绘示例：只使用车厢内真实声音 + 手绘动画声音）

## 二、三种模式的写法差异

| 模式 | 要点 |
|---|---|
| 多模态参考 | 每个素材写角色：`@图片1 是人物参考（锁脸），@视频1 是动作参考` |
| 图生视频（1 张图） | 明说是**首帧**还是**尾帧** |
| 图生视频（首+尾帧） | H3 不自动加切镜，只补两帧之间的动作、光影、声音 |
| 纯文生 | 描述更具体：主体外观+场景细节+动作+风格都要写清；
  用「大全景交代空间 + 中景承载动作 + 特写强调细节」分层写法 |

## 三、官方踩坑表（生成前逐条自检）

| 常见问题 | 怎么改 |
|---|---|
| 只写一段话没分段 | 按三段公式拆开写 |
| 素材上传了但没说用途 | 补一句「@图片1 是 XX 参考」 |
| 想用音乐但说「不要 BGM」 | 矛盾，删一个或分场景写 |
| 想一镜到底但写了很多分镜 | 全文保持一段情节描述，删掉【镜头 N】结构 |
| 想要主角脸一致但没传图 | 上传人物参考图并标注「人物参考」 |
| 提示词太短（无素材参考时） | 至少写出主体外观 + 场景细节 + 动作 + 风格 |

## 四、运镜与切镜专项

- 运镜四段式：起点 → 路径 → 速度变化 → 落点
  （例："从桌沿低角度起幅，缓慢上摇并前推，末段加速落在人物眼部特写"）
- **环绕运镜不写"环绕"**：用 `truck left + pan right` 或 `truck right + pan left`
- 切镜风格：普通切镜（cut）/ 叠化（fade）/ 随节奏卡点切 / 快切
- 相邻镜头景别必须跨档；视角变化 30°–90°
- 人物露脸只在近景/特写；远景用背影、侧背或环境空镜

## 五、文字渲染防乱码（官方 Tips）

提示词里出现乱码时：把文字以图片形式作为参考图提供，
并在提示词中明确写——"这张内容必须按'图片'来理解，不能按'文字'来处理。"

## 六、失败模式规避（app 内部 failures 决策卡）

| 失败模式 | 规避方法 |
|---|---|
| constraint-negation | 负向词反而激活被禁对象；改写为期望的可见状态（"无人的街道"→"空荡的街道"）。
  例外：官方示例中"禁止项"章节属于结构化白名单语境，可照用 |
| medium-drift | 每条 prompt 锁一种介质，末尾加 `Medium: <one primary medium>` |
| intent-overreach | 用户的修改指令近乎原样保留，不过度扩写 |
| character-refs | 抽象氛围词保不住身份；写具体可见名词清单；同一角色跨视频复用同一组锚参考图；
  禁止用已生成的视频片段做参考（会漂移） |
| era-disambiguation | 年代风格绑定地域+媒介（"Y2K 东京 DV 质感"而非"Y2K 风格"） |
| spoken-video | 对白让模型原生直出，不写"唇形同步"这类技术词 |

## 七、真实感与皮肤（photoreal-skin）

- 皮肤过平像蜡 → 补微纹理、局部透光、自然色差
- 透光只发生在薄处（耳缘、鼻翼），不要整脸发光
- 近景真人四件套：SSS 暖透感、毛孔、T 区微油光、绒毛微汗（近景全带，中景至少 2 项）
- 官方真人感句式："真实哑光皮肤、干净高级、自然毛孔、轻微皮肤纹理，不要油亮 AI 美颜脸"

## 八、台词/口播预算

- 中文语速 3–4 字/秒：5 秒 ≤18 字、10 秒 ≤35 字、15 秒 40–55 字
- 超预算：删词或拆镜，禁止指望模型加速念完
- 黑名单（命中即重写）：震惊体、"别划走"、绝对化宣称

## 九、官方高分示例句式

- 品牌片："制作一支 16:9 横版高级时尚品牌视频。整体氛围、场景和胶片质感参考图1；
  产品资产参考图3；人物资产参考图2。核心故事：……。整体气质高级、冷感、克制，剪辑灵动。"
- 短剧："生成一支 15 秒、9:16 竖屏……短剧预告片段。男女主外形参考图1，场景参考图2，
  保持身份一致。人物以中近景、特写为主，突出脸、眼神与关系张力。"
- 实拍质感："画面带有智能手机单手拍摄的手抖、近距离对焦的犹豫、逆光曝光波动。
  要像在家中慌忙拍下某个不可思议事件的自然质感。"
- 一致性清单式："图2作为固定人物参考，保持黑色半扎长发、银色镂空发冠、黛蓝发带、
  浅色层叠汉服……一致。"
- 精准编辑式："将原视频中的桌面替换为标准办公室工位，新桌透视比例与原镜头完全匹配，
  光影投射方向严格一致……镜头运动轨迹、运动时序与速度保持 100% 不变。"
- 音乐律动→画面动效映射（官方大字幕 MV 示例提炼）：
  hi-hat roll → 文字细碎微震/跳帧；snare → 文字猛然放大、画面硬切；
  bass hit → 低频压屏、文字纵向拉伸/横向压缩；vocal 重音 → 嘴型/下颌/头部点拍同步
- 变形连续性（官方手绘特效示例提炼）：每次变形保留前一形态的痕迹元素
  （线条、局部特征），让观众感到是同一存在连续变形，而非新角色凭空出现

## 十、快速路径（三段式）适配说明

三段式快速路径是「文生 → 首帧图 → 图生视频」模式，适合一句话快速出片；
正式生产（调研、资产、分镜、批量、长视频）按 `production-workflow.md` 执行，
超过 15 秒或多镜头叙事先读 `long-video.md`：
- 节点 1（提示词增强）产出的提示词同时用于生图和生视频，须保证**画面描述即首帧画面**，
  动作演进部分写清"从该画面开始"的演进过程
- 快速路径当前支持 720p/1080p 参数（官方原生为 768p/1440p，语义对应）
- 快速路径节点无参考素材上传能力，`参考素材说明` 段跳过，重点写足核心创意与画面过程；
  素材上传、多模态参考（图/视频/音频）、首+尾帧与精准编辑默认打包节点**未实现**，
  只可作为提示词创作参考，不得声称本流水线支持
- 单条 5 秒片：1 个 shot 即可；不写切镜结构；台词 ≤18 字或不写台词
