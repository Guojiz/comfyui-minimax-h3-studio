# 创作质量门

> 正式提交生成前、决定是否用参考图、核对节奏与时长、改写提示词或准备返工时读取。

创作层三扇门：参考图决策门（P0）、节奏与时长门（P0）、提示词与返工规范（P1）。
生成花钱之前按序过一遍；三扇门都用清单和表格，尽量机械可执行。

## 一、P0 参考图决策门

### 先回答：到底需不需要参考图

| 情况 | 更合适的输入 |
| --- | --- |
| 风格、媒介、氛围可以用文字说清 | 纯文本提示词 |
| 必须保持主体身份、构图、材质或品牌特征 | 简单参考图 |
| 需要从参考图继续演进动作 | 只锁静态特征的简单参考图，不在图里写死动作 |
| 只因为 "workflow 有 LoadImage" | 不用图；主动选择匹配 workflow 的纯文本路径 |

"workflow 有 LoadImage" 不等于创意上必须使用参考图。正式提交前先判断是否确实需要，再决定是否
上传素材；需要纯文本时，主动选择不需要素材输入或素材可空的 workflow。

### 参考图只锁定必须保持的部分

| 可以锁定 | 不要锁定 |
| --- | --- |
| 主体身份（脸、服装、道具） | 完整叙事结果 |
| 构图与画幅关系 | 具体运镜轨迹 |
| 材质与表面特征 | 动作过程与形变结果 |
| 品牌特征（Logo、名称、产品形态） | 最终成片的全部细节 |

在提示词里写明参考图锁定的范围与自由度，例如：

```text
参考图锁定：主体身份、构图与材质。动作和运镜按文字描述自由演进，不逐帧复刻参考图。
```

### 提交前检查

- [ ] 确定需要参考图，而不是因为 "workflow 有 LoadImage" 所以传图
- [ ] 参考图只锁定必须保持的主体/构图/材质/品牌特征
- [ ] 构图、尺度、物理关系自然：主体大小、透视、遮挡、比例没有明显冲突
- [ ] 没有提前塞入完整叙事结果，限制后续运动与形变
- [ ] 是否应先做更简单的参考图（风格卡、剪影、色板），而不是一次到位
- [ ] 参考图来源与授权：敏感、肖像、版权素材未获授权不提交

### 决策流程

```text
判断是否需要参考图
→ 不需要：走纯文本，选匹配 workflow
→ 需要：先做最简单可用的参考图
→ 锁定范围只保留必须项
→ 检查构图/尺度/物理关系自然
→ 检查没有写死运动与形变
→ 提交
```

## 二、P0 节奏与时长门

不设置机械事件数量上限。指标不是"塞了多少个事件"，而是每个视觉节拍是否有足够时间成立。

### 节拍时长预算

| 总时长 | 结构预算 |
| --- | --- |
| 5 秒 | 一次主要动作或变化；结尾约 1 秒落版 |
| 8 秒 | 建立约 1.5 秒；发展约 3–4 秒；结果约 1.5 秒；落版约 1.5 秒 |
| 12–15 秒 | 最多容纳清楚连续的阶段；保持单一主要视觉因果 |

预算不是硬性帧级要求，是按秒分配的节奏参考：每个阶段在对应秒数内必须有可辨认的推进。

### 内容装不下的处理

- 先删减：保留单一主要视觉因果，去掉旁支动作。
- 再拆分：拆成多个生成片段后用剪辑拼起来，不靠压缩动作硬塞。
- 禁止：无限延长单次生成，或把两个完整因果塞进一个片段。

### 提交前检查

- [ ] 建立：开头 1 秒左右有清楚起点
- [ ] 发展：主要动作或变化有足够时间展开，没有跳切式推进
- [ ] 结果：变化到达可辨认的落点
- [ ] 转场：镜头内或镜头间过渡自然，无生硬切断
- [ ] 文字：唯一允许文字能在时长内读完（参考 3–4 字/秒台词预算）
- [ ] 声音节奏：对白/BGM/环境音与节拍匹配
- [ ] 无关动作：没有与主要因果无关的额外动作
- [ ] 事件数：检查的是"每个节拍是否成立"，不是计数达标

### 常见失败

| 失败 | 修复 |
| --- | --- |
| 8 秒内容塞进 5 秒 | 缩短建立/结果或拆成两段剪辑 |
| 两个因果抢节奏 | 只保留一个主要视觉因果，另一个拆到后续片段 |
| 结尾没有落版 | 保留约 1 秒收束，给观感一个终止点 |
| 事件多但都不成立 | 回退脚本，减事件，不靠延长 duration 兜底 |

## 三、P1 提示词与返工

### 信息分层：剧本、声音/文字、技术参数分开

| 层 | 内容 | 去向 |
| --- | --- | --- |
| 导演剧本 | 主体、地点、事件、动作、镜头、风格 | 提示词的创意与画面过程 |
| 声音与文字 | 台词原文、唯一允许文字、BGM/对白/环境音/静音策略 | 台词预算与声音声明 |
| 技术参数 | duration、分辨率、workflow、seed、输出路径 | 提交参数，不进导演描述 |

- 一个生成片段只保留一个主要视觉因果。
- 明确唯一允许文字：把允许出现的文字原文写进提示词；其他文字视为乱码/违规。
- 明确声音策略：纯器乐、对白、环境音、静音四选一或白名单式组合，不留下"未定义"。
- 客户只要剧本时，只交付脚本/描述，不输出模型文件、节点编号或内部参数。

### 失败先记录现象，再决定改哪里

返工前先留证据（四要素：失败路径、现象、已改参数、结果），再按现象选变量：

| 现象 | 优先检查 | 主要变量 |
| --- | --- | --- |
| 主体漂移、特征不一致 | 参考图与描述是否锁定主体 | 参考图或 prompt 主体清单 |
| 动作跳变、形变 | 画面过程是否写得太跳跃 | prompt 动作分步 |
| 节奏/时长不对 | 节拍预算是否合理 | 时长或剪辑方案 |
| 技术失败（黑帧、截断、provider 报错） | 参数与 workflow | 时长/分辨率/workflow |
| 文字乱码 | 是否给了原文和允许范围 | prompt 文字原文 |
| 声音不符 | 声音策略是否明确 | 声音声明或后期混音 |

### 单变量纪律

- 一次只改一个主要变量（prompt、参考图、时长、生成方式，任选其一）。
- 不重复提交完全相同任务；相同内容重发不产生新信息。
- 同一策略连续失败 3 次、预算耗尽、目标漂移或需要新授权时停止，请求客户决策。
- 新结果先标 `candidate`，通过后再标 `approved`；旧候选不覆盖。

## 四、提交前总查

- [ ] 参考图决策完成：需要就锁范围、检查自然度；不需要就选纯文本路径
- [ ] 节拍预算完成：建立/发展/结果/落版/转场都有时间
- [ ] 唯一允许文字已写原文，声音策略明确
- [ ] 剧本、声音/文字、技术参数分离，客户视角看不到模型文件与节点编号
- [ ] 一个片段只有一个主要视觉因果
- [ ] 失败重试已留四要素证据，一次只改一个变量
