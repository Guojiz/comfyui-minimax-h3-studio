# 🐙谁是 MiniMax Design 

**MiniMax Design** 是一个运行在本地桌面的 AI Agent 创作平台，将脚本、图像、视频、配音到成片导出的完整内容生产流程整合在同一个工作台中。不同于单点 AI 工具，Design 以 Agent 自动编排任务、调度模型、协同执行，团队只需专注决策，无需手动切换工具。



我们相信，好的创作不是从“生成”的那一刻，或“一句话做XXX”。它需要前期调研、规范思路和创意制作的融合。

**因此，MiniMax Design是第一款集合了「文本调研\+多媒体制作\+无限画布」的AI Agent 生产平台。**



**它不是单纯的"出图出视频工具"。** 五大核心特点包括——

1. 🎬 **全链路生产，告别工具割裂** — 从搜索/调研、脚本、分镜、图片与视频生产，到最终交付，支持全流程内容生产与并行项目同步运行。

2. **🤖 Agent 智能编排** — 不需要手动抽卡、手动连工作流。你提供灵感和想法，Design 的 Agent 自动规划、调度最适合的模型。

3. 🧠 **Skill 技能库** — 将你的工作流、品牌规范、创作偏好和生产流程生成可复用的 Skill。还有超过100\+ Skill的能力广场与精选插件。

4. 💾 **Memory 记忆** — Design 记住你的偏好、风格标准和历史选择。用得越久，它越像你自己的专属创作团队。

5. **打通本地工作流**——可以直接让Agent读你的PDF / Word 文档照计划执行，整理电脑素材文件夹，一键导出至剪映 / DaVinci / Adobe

## Skill与插件广场

**什么是Skill ？**

在MiniMax Design 里，Skill可以理解为创作的技艺——这也是一套给AI Agent用的、固定可复用的工作流。

它可以是行业规范与标准，比如短剧制作的完整流水线：剧本 → 分镜 → 角色与场景 → 图生视频 → 配音配乐 → 合成输出。也可以是创作偏好与审美准则，比如"品牌视觉风格偏简洁、少文字"。

### 5\.2 自定义Skill

1. **方式一：直接说需求，让 Agent 来找或现场做**
 在对话框里告诉 Agent 你想要什么样的 Skill，比如「帮我做一个产品替换 Skill，保持原画风」，Agent 会直接帮你生成，最后检查保存。

2. **方式二：先创作，再把过程存成 Skill**
 在对话中完成几个步骤或整个创作流程后，输入 `/skill-creator`，或者直接告诉 Agent「把当前对话总结成 Skill」，它会自动把这套流程打包保存下来。

3. **方式三：基于已有 Skill 修改**
 在使用某个 Skill 的过程中，如果遇到不满意的地方，随时可以叫停、调整细节。改完觉得不错，告诉 Agent「保存为我自己的 Skill」，下次就能直接用改好的版本了。

4. **方式四：上传已有资料来创建**
 手头有经验文档、笔记，或者其他 SKILL\.md 文件，直接上传给 Agent，描述你想要的 Skill 是什么，它会根据资料帮你生成。

> 💡 Skill 创建完成后，推荐用 `/skill-reviewer` 检查一下质量——让 Agent 在使用时发挥得更稳定。
