# 渐进制作长视频

> 成片超过单次模型时长、多镜头叙事、短剧、长广告或 MV 时读取。

## 原则

长视频不是把 `duration` 调长，也不是先承诺一套完整昂贵生成计划。先找到当前最大风险，用较小可见
产物验证，再继续扩展：

```text
理解目标和已有素材
→ 验证风格/角色/场景
→ 验证关键动态镜头
→ 形成必要的镜头关系
→ 逐段生成和局部修复
→ 粗剪验证节奏
→ 补齐声音、字幕和交付
```

Agent 可以先写简短节奏骨架，但只有当完整镜头表确实能降低返工时才建立。客户要求一步步看，就在
每个关键产物后停下；方向稳定且客户授权时，才批量处理同类低风险镜头。

## 选择第一个验证点

| 风险 | 最小验证产物 |
| --- | --- |
| 视觉风格 | 少量效果图或风格卡 |
| 角色一致性 | 角色/服装/道具参考和一个测试镜头 |
| 场景连续性 | 场景卡、地标和两个相邻镜头的静帧 |
| 复杂动作 | 最难的 4–5 秒关键片段 |
| 叙事节奏 | 文本分镜或使用已有素材做粗剪 |
| 声音策略 | 一段对白/BGM/环境音小样 |

通过验证的产物登记为 `approved`；未通过只改相关层，不继续生成其下游。

## 分段与连续性

单段时长服从当前实例/外部服务配置，通常保持一个主要视觉事件。每段需要时记录：

- 承接的上游资产和上一段末状态；
- 主体身份、服装、道具和不可改变特征；
- 场景地标、光照、色温、天气和时间；
- 景别、运镜、动作、台词/音效及段尾落点；
- 实际使用的 workflow、实例/外部服务配置和 run。

这些事实写入资产关系或相应分镜文件，不要求所有项目使用同一固定表格。台词以模型和语言实测为准；
可先用中文约 3–4 字/秒做预算，再通过样片校正。

## 逐段生成

1. 优先生成最能暴露整体风险的关键片段，而不是机械从第一秒开始。
2. 拿到结果立即做技术、内容、连续性和声音 QC。
3. 新结果先为 `candidate`；客户接受或正式下游采用后改为 `approved`。
4. 只重做失败片段及依赖它的下游，旧批准版本不覆盖。
5. 方向稳定后，可以在清楚的预算范围内处理同类镜头；新方向或扩大成本重新确认。

## 粗剪与最终合成

已有足够片段时先做粗剪，检查钩子、推进、转折、收尾和段间落点，再决定缺哪些镜头。字幕、响度、
转场、容器和简单节奏修复优先用 FFmpeg/剪辑工具，不为确定性后期问题重新调用生成模型。

最终合成只使用 `assets.md` 中当前 approved 的版本。检查时长、分辨率、帧率、音轨、黑帧、文字和
授权，并保留从成片回溯到片段、参考资产、workflow 和决定的关系。

## 常见失败

| 失败 | 修复 |
| --- | --- |
| 角色/场景漂移 | 回到稳定参考资产，先重做一个相邻测试片段 |
| 节奏断裂 | 用已有片段重剪或补最小桥接镜头，不整片重抽 |
| 动作接不上 | 明确上一段末状态和下一段起点，只重做接缝附近 |
| 声音突兀 | 统一环境音/BGM 策略，确定性混音优先 |
| 长期越做越偏 | 重读 `decisions.md`，生成较低成本方向校正产物 |

连续失败 3 次、预算耗尽、目标漂移或需要新授权时停止并请求客户决定。
