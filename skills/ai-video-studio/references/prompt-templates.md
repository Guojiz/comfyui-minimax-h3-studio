# 完整提示词模板与范例

> 配套 `prompt-craft.md`（方法论，官方手册要点已提炼其中；原文版权归原厂商，不随仓库分发）。
> 所有模板遵循官方三段公式：`完整提示词 = 参考素材说明 + 核心创意 + 画面过程说明`（长片追加第四段【整体要求补充】）。
> 写 prompt 前先过 `prompt-craft.md` 第八节台词预算与第三节踩坑表。

## 一、空白模板（填空用）

```
【参考素材说明】（无素材时整段跳过）
@图片1 是（人物参考（锁脸）/ 物体参考 / 场景参考 / 关键帧（首帧/尾帧）/ 风格参考 / 构图参考…），用途：……
@视频1 是（动作参考（锁动作）/ 运镜参考（锁运镜）/ 视频编辑…），用途：……
（想保持的特征逐项列出：发型、服装、材质……；音频复刻须附歌词原文）

【核心创意】（一句话锁全片：主体 + 地点 + 事件 + 题材风格 [+ 特殊运镜]）

【画面过程说明】（按时间轴/shot 分段，每段写齐：景别 + 内容 + 运镜 + 动作 + 台词 + 音效）

▍景别切换：……
▍人物规则：……
▍禁止项：……
▍环境音：……
```

## 二、完整范例 A：5 秒纯文生视频（本流水线直接用）

> 无参考素材 → 跳过素材段；单 shot 不写切镜；台词 ≤18 字；末尾锁介质。

```
清晨六点的海边小镇码头，一位穿卡其色风衣的中年男人站在木栈道尽头，手握一杯冒热气的咖啡，海鸥在他头顶盘旋。写实电影质感，冷色调，轻微胶片颗粒，一镜到底。

0-5秒：大全景，男人背对镜头站在栈道尽头，海面晨雾弥漫，远处渔船灯光闪烁。镜头从栈道中段缓慢前推，掠过湿漉漉的木栏杆。男人没有转身，风衣下摆被海风吹动，他举起咖啡杯喝了一口。海鸥鸣叫，海浪拍打木桩的声音由远及近。台词无。

Medium: photoreal live-action footage
```

## 三、完整范例 B：首帧图生视频（1 张首帧图）

> 明说这张图是**首帧**；H3 只补动作、光影、声音；文字内容必须给出原文。

```
@图片1 是关键帧（首帧），画面内容必须严格延续，主体外观（黑色半扎长发、银色镂空发冠、黛蓝发带、浅色层叠汉服）保持完全一致。

一位穿浅色汉服的年轻女子（@图片1）在竹林中缓缓转身，衣袂随转身展开，阳光穿过竹叶洒落光斑，古典国风，电影质感。

0-5秒：中近景起幅，女子侧身静立（与首帧一致）。她缓慢转身面向镜头，发冠流苏轻微晃动，衣摆旋开。镜头以 30° 弧度跟随她的转身，从侧脸转到正脸。她抬眼望向镜头，嘴角微扬，不发一言。竹叶沙沙声，远处流水声。

Medium: photoreal live-action footage
```

## 四、完整范例 C：15 秒品牌片（多参考素材，API 平台直调场景）

> 当前 ComfyUI 流水线暂不支持素材上传；此模板用于支持多模态参考的 API 直调。素材按上传顺序编号，逐个写清用途。

```
@图片1 是场景参考，用途：整体氛围、场景与胶片质感；@图片2 是人物参考（锁脸），用途：演员外形与服装；@图片3 是物体参考，用途：产品资产（瓶身、标签）。

制作一支 16:9 横版高级时尚品牌短片。一位穿黑色高领衫的女演员（@图片2）站在黄昏光线下的美术馆长廊（@图片1），手中握着产品瓶身（@图片3），冷感、克制、高级，剪辑灵动，全程无对白。

0-4秒：大全景，长廊尽头逆光剪影，女演员缓步走入画面，镜头缓慢横移跟随。环境音：空旷展厅的脚步声、远处低鸣的空调声。
4-9秒：中景，她停步，特写她的手指轻抚瓶身标签，标签上印着 "LUMIÈRE PARIS"。镜头推近，窗光在瓶身表面滑过。环境音：布料摩擦声、极轻的瓶盖旋动声。
9-15秒：近景，她微微仰头，闭眼呼吸，光影从冷转暖。镜头缓缓后拉，长廊柱影掠过她面部，切至瓶身正面特写，产品占据画面黄金位。环境音渐弱至静，字幕浮现 "LUMIÈRE PARIS"。

▍影像风格：胶片质感、低饱和、克制的暖调逆光
▍文字包装：所有出现文字必须精确呈现原文 "LUMIÈRE PARIS"
▍律动规则：剪辑节奏先缓后收，最后两秒留白
▍景别切换：大全景 → 中景 → 近景，逐级推进，无跳切
▍人物规则：女演员始终优雅、静止感强，动作幅度小
▍禁止项：无廉价闪光特效、无快闪字幕
▍环境音：白名单式——仅展厅脚步声、空调低鸣、布料声、瓶身声

Medium: photoreal live-action footage
```
